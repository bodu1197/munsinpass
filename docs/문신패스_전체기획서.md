## 1. 문신사법 핵심 정보

### 법령 개요
- **법령명**: 문신사법 [법률 제21070호]
- **공포일**: 2025년 10월 28일
- **시행일**: 2027년 10월 29일
- **소관부처**: 보건복지부

### 주요 일정 타임라인
| 일정 | 내용 |
|------|------|
| 2025.09.25 | 국회 본회의 통과 (찬성 195 / 기권 7) |
| 2025.10.28 | 대통령 공포 (2년 유예기간 시작) |
| 2026년 (현재) | 시험 준비 기간 · 예산 6억 3,500만원 |
| 2027.10.29 | 법 시행일 · 면허제도 본격 개시 |
| 2027년 말 | **첫 국가시험 시행** (국시원 주관) |
| ~2029.10 | 기존 종사자 임시 특례 기간 종료 |

### 국가시험 핵심 사항
- **주관**: 보건복지부 (한국보건의료인국가시험원 위탁)
- **시험 형태**: 필기 + 실기
- **시험 주기**: 매년 시행
- **응시 자격**: 학력·전공·경력 무관 — 누구나 응시 가능
- **세부 사항**: 시험과목·수수료 등은 대통령령으로 확정 예정

### 면허 취득 3단계
1. 국가시험 합격
2. 위생·안전 교육 이수
3. 시·군·구 업소 등록

### 기존 종사자 특례
- 법 시행(2027.10.29) 후 최대 2년간 시험 없이 임시 등록으로 영업 가능
- **단**, 2029년 이후에는 국가시험 합격·면허 필수
- "기존 종사자" 인정 기준은 시행령에서 확정 예정

### ⚠️ 핵심 주의사항
> "2029년까지 시험 없이 일은 할 수 있지만, 시험은 2027년 말부터 바로 시작된다.
> 미루다가 2029년에 떨어지면 그날부터 즉시 불법이 된다."
> 기존 문신사든 신규든 2027년 말 첫 시험부터 최대한 빨리 취득할 것을 권장.

## 4. AI 문제 출제 시스템

### 파이프라인 5단계
1. **사용자 데이터 분석** — 틀린 문제·정답률·과목별 약점 집계
2. **프롬프트 생성** — 약점 과목·난이도·출제 유형 조합
3. **Claude API 문제 생성** — JSON 구조화 출력 (문제·보기·정답·해설·법령 근거)
4. **품질 검증** — 중복 제거·오류 필터·관리자 검토 큐
5. **출제 & 피드백 수집** — 오답 누적 → 다음 세션 반영 (강화 루프)

### Claude API 프롬프트 예시
```
시스템: 당신은 문신사 국가시험 문제 출제 전문가입니다.
반드시 JSON만 출력하세요.

출력 형식:
{
  "question": "문제 텍스트",
  "options": ["①..","②..","③..","④.."],
  "answer": 1,
  "explanation": "해설 텍스트",
  "law_reference": "문신사법 제N조",
  "difficulty": "중급",
  "subject": "위생·감염"
}
```

### 기술 스펙
- AI 모델: Claude Sonnet (claude-sonnet-4-20250514)
- 문제 생성 속도: 1문제당 약 2~3초
- 초기 문제은행: 수동 300문항 + AI 생성 700문항
- 난이도 분류: 초급 / 중급 / 고급
- 중복 방지: 임베딩 유사도 검사 (cosine similarity)
- 비용 절감: 생성된 문제 캐싱 후 재사용

## 6. 운영 방침 — 전액 무료

문신패스는 **모든 기능을 완전 무료**로 제공합니다. 이용자는 단 1원도 지불하지 않으며,
유료 플랜·결제·구독·기능 잠금이 일절 없습니다.

### 무료 제공 범위 (전 기능)
- 과목별 문제풀이 (학습 모드 · 시험 모드)
- 실전 모의고사 **무제한**
- AI 오답 재출제·분석, 오답노트
- 실기 체크리스트 · 핵심 요약
- 커뮤니티 읽기·쓰기
- 시험 정보·일정 D-Day 알림
- 학습 통계·점수 추이·합격 예측
- **회원가입 없이도** 핵심 학습 기능 이용 가능

### 운영 지속 방안 (이용자 부담 0원)
- 비영리·공익 목적 운영을 원칙으로 함
- 서버·AI 비용은 운영자 자체 부담 또는 **자발적 후원**으로 충당 (선택 사항, 강제 없음)
- 이용자 대상 **유료화·기능 잠금·개인정보 판매를 하지 않음**
- 운영비 절감을 위해 정적 데이터 우선·캐싱·경량 인프라를 적극 활용
